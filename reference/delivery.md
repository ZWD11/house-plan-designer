# 交付：全功能验收 + 告诉用户什么

### 6. 交付

```bash
python scripts/build.py <工作目录>/spec.json -o <图片同目录>/<户型名>-装修设计器.html --zip
```

`--zip` 同时打一个 `<户型名>-装修设计器.zip`：HTML + 原图 / 底图 + 生成脚本 + spec.json + 截图，用户问“怎么下载”时直接给这个（云端环境尤其要给）。

**交付前必须跑全功能验收，全部通过才能交付**（真显卡、无头浏览器把每个按钮、工具、图层、面板、弹窗、导出都实际操作一遍，约 15~20 分钟）：

```bash
node scripts/qa.mjs <户型名>-装修设计器.html <工作目录>/qa          # 加 --quick 跳过 PDF 和光线追踪（约 8 分钟）
python scripts/qa_files.py <工作目录>/qa/downloads                   # 导出的 PNG / DXF / PDF / CSV / JSON / 分享文件能不能正常打开
```

- **电脑性能一般时**（验收卡、超时一片）：验收进程默认就是“低于正常”优先级（Chrome 跟着降），电脑照常能用；再加 `--lite`（1280×800、快速画质、超时放宽一倍，判定标准不变）。
  改动只涉及某一块时先跑那一组：`--only 2d|3d|walk|smart|screen`（逗号分隔，也可以写步骤名关键词，如 `--only 管线,漫游`），约 1~3 分钟；
  有失败项时 `--retry <输出目录>/report.json` 只重跑失败项所在的组。交付前仍要完整跑一遍（可以 `--lite --quick`）。
  **不要和视频渲染、另一个验收、录屏同时跑**：抢显卡会让 3D / 漫游 / 中控几十项一起超时，看起来像设计器坏了。
- `qa/report.md` 每一项 ✅ / ❌ + 原因 + 截图；有 ❌ 先分清是脚本点错位置还是设计器真有问题，真问题修设计器（`npm run skill:sync` 后重新 build），**不能带着 ❌ 交付**。
- 判定规则：任何页面报错 = 失败；界面上出现 NaN / undefined / Infinity = 失败；操作后状态没变（加了家具数量没变、撤销没恢复）= 失败；导出没下载到文件 = 失败；3D 画面空白 = 失败；夜里中控文字对比度不够 = 失败；1280×720 ~ 1920×1080 下按钮超出 / 重叠 = 失败；手机尺寸打开平面超出屏幕 = 失败。
- 自动检查之外**一定要人工过一遍 `qa/shots/`**（每一步一张图）：重点看文字有没有被截断 / 压住、弹窗内容、3D 风格和配色、中控卡片、手机尺寸。
- 改过家具库或 3D 家具建模时，再跑 `node scripts/qa_furniture.mjs <html> <工作目录>/furn`：全部家具排成网格分块拍 3D，对照 `list.txt` 逐件看模型对不对（注意广角边缘有透视变形，存疑的拉近单独拍）。
  改过风格款或自由模型时跑 `node scripts/qa_styles.mjs <html> <工作目录>/styles`：一行一个风格（默认款 + 9 种）× 10 类家具、最后几行全部自由模型，逐行拍近景。
- qa.mjs 已包含：家具库分类 / 搜索 / 风格换款、自由模型画轮廓 → 改材质倾斜 → 阵列 → 撤销、手画管线 → 纠错报悬空 → 一键纠错 → 删自动走线 → 报下游断电 → 恢复、漫游视高 / 视距 / 视角。

- **没有显卡**（云端 / 虚拟机）：qa 自动进慢速模式，渲染类步骤超时记「⚠ 未验证」不算失败，但必须人工看对应截图，并在交付时说明“3D 相关 n 项在无显卡环境下按截图人工确认”。见 `env-cloud.md`。

交付时告诉用户：
- **待确认清单**（开工时问过、或识图时估的，集中列出）：层高、楼板厚、看不出窗台高的玻璃 / 窗、推断的承重墙（设计器里标“待确认”、批注页有）、公共区是否还原、图纸自相矛盾的尺寸（check 的 `dimConflicts`）、不认识的符号、按“一比一还原”还是“补最优搭配”。这些写进 spec 的 `comments` / `heightFrom: "estimated"` / 洞口 `unsure`，用户打开就在「批注」页看到
- 五个对账的结果（墙体 wallaudit、反向 coverage 的一致度 / 漏墙 / 偏位、尺寸链 dims、门开向 doorcheck、家具摆放）和「图上符号 → 建模」表；房间面积对账（图上标的 vs 设计器算的）
- HTML 的路径，附上 `plan2d.png` 和 `view3d.png`
- 识别结果和原图哪里可能不一致、比例是不是估算的；CAD 图纸要说明承重墙是按“涂黑 + 厚度”判断的（原始结构图常把所有原墙都涂黑），以物业结构图为准；原图是门洞、方案里装了门的要说明
- 新功能（告诉用户怎么用）：
  - **左右面板**：舞台边上的小把手（或按 `[` / `]`）收起 / 展开左栏、右栏，拖面板边缘调宽，双击边缘在窄 / 宽之间切换；漫游视角面板点标题（或按 H）收起成小标签。
  - **选中家具，左栏家具库自动跳到它所在的分类并高亮**；打开“点款式替换”后点库里另一款，就地替换（位置、朝向不变，背面贴墙）。
  - **吊顶**：顶面图层选房间 → 属性里选平顶 / 边吊 / 回字叠级 / 悬浮 / 铝扣板 / 木饰面，调下吊高度、宽度，勾“灯槽”自动放灯带、窗帘盒、石膏线；顶面图注标高 ▽2.650；局部吊顶在家具库「吊顶」里画轮廓。
  - **灯带 / 磁吸轨道 / 线性灯**：水电面板灯具组或家具库「吊顶」里点“画线”，在平面上逐点画；属性里改安装位置（贴顶、柜底、踢脚、床底、镜后）、色温，看长度、功率、驱动电源；关联开关后 3D 里能开关。
  - **户外**：家具库「户外庭院 → 场地」画草坪 / 碎石 / 铺装 / 木平台 / 水景 / 花境任意轮廓；还有绿篱、花坛、棕榈、竹子、景观石、花架廊、户外沙发、庭院灯、地埋灯等。
  - **自由造型工作台**（顶栏「造型」）：在地面或任意部件的面上画矩形 / 圆 / 多边形 → 拖动推拉成体（往里推 = 挖洞），推拉工具点任意面改尺寸，旋转成型、放样（石膏线 / 踢脚线 / 圆管 / 扶手截面），移动 / 旋转 / 缩放手柄，复制、镜像、阵列、布尔挖空，每个部件单独选材质；Shift + 点多选整组移动 / 旋转 / 复制 / 镜像；拉伸体可“抽壳”做柜体、抽屉、花盆；顶栏「模板」里有餐椅、茶几、边几、书架、悬空电视柜、床头柜、吊灯、花盆、格栅墙起手；右上角显示整体尺寸；输入数字回车 = 精确尺寸；“完成”放进方案，“存入造型库”以后在「自由模型 → 我的造型」里拖出来用。
- 打开后的用法：左侧“户型”面板可以勾选“显示底图”对照原图；“载入初始户型”随时恢复到这个户型；其余功能（3D 漫游、家具、水电、吊顶、拆改、报价、导出 PDF/分享文件）和原设计器一样；「导出图纸 → CAD 平面布置图（DXF · 国标 / 装修）/ CAD 水电点位图（DXF）」导出 DXF R2007（文字 UTF-8，中文不乱码；模型空间 1:1 mm），按 GB/T 50001 / 50104 出图习惯：分图层并设线宽（墙柱粗线 0.5、门窗 0.25、家具尺寸 0.13）、承重墙涂黑、新砌墙 45° 斜线图例、拆除墙虚线、门开启线细实线、定位轴线 + 轴号（1、2、3… / A、B、C…，不用 I O Z）、尺寸两种导出：国标三道（门窗洞口 / 轴线 / 总尺寸）或装修四道（多一道墙厚 + 净距），间距 10mm、第一道离外轮廓 10mm，短段数字错开 + 引出线；每段尺寸都是真正的 DIMENSION 标注对象（标注样式 GB：45° 建筑斜线、字高 3、DIMSCALE = 比例，数字由 CAD 按定义点量，和图形一致）；门窗编号（M / TLM / DK / C / GC / TC + 宽高分米，撞号加 a、b）+ 门窗表（毫米实数、数量、窗台高、入户门）、指北针、图名 + 比例、A3/A2 图框 + 标题栏，比例自动选（优先 1:100），可再用 cadvec.py 读回来；选中橱柜、定制柜、浴室柜、淋浴房、中岛，属性面板有「定制」区：橱柜可改一字 / L / U 形、进深、台面高厚和颜色、水槽灶台在哪一段和位置宽度、吊柜、烟机、高柜，定制柜可改每列宽和类型、L 形转角、顶柜、踢脚、拉手、顶天立地，2D / 3D / 立面 / 报价 / 水电同步（冰箱洗衣机等成品家电保持标准尺寸）；3D 里点墙上的开关能开关对应的灯（夜间模式最明显），门、窗帘、电视、台灯也能点；漫游时附近的开关 / 插座 / 小物件头上有点位标记（被墙挡住的不显示，白天黑夜都看得见，开关标记随灯亮变色，悬停看名称、点标记直接操作），准星对着的东西按空格 / 回车操作，T 显示 / 隐藏标记，漫游面板里可按开关 / 插座 / 小物件分别开关标记；水电面板有“一键布置水电”和「管线排布」（全部 / 电路 / 网线 / 给排水切换，插座回路走地或走顶、给水走顶或走地，回路表、材料清单 CSV，点中一段管线拖动改走向、恢复自动走线，选中插座改所属回路；DXF 水电图按系统分图层带管线）；3D「⚡ 管线」把管线按真实高度放进模型、墙半透明；
管线按行业做法排（墙面横平竖直、地面沿墙分道或两点一线、厨卫电线走顶、水走顶、电上水下不同槽、强弱电 ≥ 300、排水 45° 斜接、电线管大弧弯，规则见 `reference/mep-rules.md`），
可以**自己画 / 改 / 删管线**：顶部「管线」工具逐点画（自动吸附点位、箱子、别的管线；可勾“自动寻路”只点两头），选中管线拖顶点、双击加拐点、Delete 删拐点或整条，右侧改系统 / 规格 / 走顶走地 / 所属回路；
水电面板「管线纠错」逐条列出悬空、穿开洞、厨卫地面埋电线、穿承重墙、排水直角、强弱电间距、水电同槽、删线导致下游断电、漏接点位、左热右冷装反等问题，点一下定位，「一键纠错」自动处理；
漫游时右下角「漫游视角」调视高（儿童 / 成人 / 高个 / 高处）、视距（第一人称 ↔ 跟随视角，退后时被墙挡住会自动拉近，能看到小人）、视角 FOV，R / F 升降视高、滚轮调视距、Ctrl + 滚轮调视角；
家具库按空间 / 类型两级分类、可搜索，顶部选风格后放进来的沙发床椅桌柜是那个风格的款式，「整套家具换成某风格」一键全换，属性里单件换款；
「造型」工具 / 家具库「自由模型」：基本体（方块、圆柱、球、锥、楔形、拱门、弧形墙、格栅、台阶、圆环、旋转体）和画轮廓拉伸体，材质、圆角、倾斜、壁厚、条数、阵列复制都能调，拉伸体拖顶点改轮廓；写实风格漫游：GTAO 接触阴影、窗户面光源（窗帘拉上会暗）、家具小倒角、布艺 / 木纹 / 乳胶漆微纹理、窗外城市远景（夜里亮窗）、室内摄影调色，顶面不再漏光；「风格」里有画质档位（流畅 / 均衡 / 高画质，默认按显卡自动选；均衡以上有布艺丝绒光泽、烤漆清漆、木纹布纹凹凸、房间反弹光、抗锯齿）；软装是鼓包的填充感垫子、带包边，被子有褶皱；☀ 面板「出图方式」可选光线追踪（three-gpu-pathtracer，首次编译核显约 1~2 分钟，有进度条、可提前结束保存，最后降噪）；3D 视图「🎨 风格」可切换写实 / 沙盘效果图（微缩模型感）/ 彩平图（正上方俯视的彩色平面图，标准门窗符号、房间名和面积、指北针、比例尺；尺寸可选不标 / 简洁 / 完整，彩平图模式下「渲染出图」直接出完整彩平图）和 12 套配色，鸟瞰、漫游、出图都保持；「导出图纸 → 彩平图（高清 PNG）」直接出一张长边 4000 像素的彩平图；房间面板里可以「自定义铺砖」（砖的长宽、灰缝、8 种铺法、纹理、砖色缝色、起铺点），2D / 3D / 报价同步，报价按整砖 + 切砖片数算；右侧总览里可以开关三类尺寸标注（外墙门窗分段、每段墙净长、房间开间 × 进深），改墙后实时重算，导出图纸也带上；☀ 面板按城市、月份、时间模拟真实日照，夜里出月亮星空，有“日照演示”；🔒 锁定后 3D 里不能拖动家具（防误触）；3D 里的动效都是平滑的：门、窗（平开窗往里转开、推拉窗滑开，3D 里点窗扇就能开关）、窗帘（一褶一褶收拢展开，可停在任意开合度）、开关灯淡入淡出、电视屏亮起、楼层切换时楼层滑开 / 滑回；3D 视图「🏠 智能中控」（演示，单层套房和多层都能用）：把方案当成装好智能家居的房子来用——墙面变成白色半透明、能看到房间里面，开着的灯在地面打出暖色光池、灯具周围有光晕（色温、亮度一调就看得出）；左侧问候、日期农历、当地日出日落、灯光 / 空调 / 窗帘开着几台和室内 PM2.5 / 温度 / 湿度曲线（模拟数据），右侧楼层（多层时 ALL = 各层拉开的爆炸视图、缓慢自转），底部灯光 / 环境 / 设备 / 扫地机 / 安防五类，3D 里设备上浮出图标，点图标镜头推到房间、弹出控制卡片：灯（色温 2700~6500K、亮度、柔和 / 日常 / 明亮）、窗帘（开合百分比、关闭 / 暂停 / 打开）、空调（温度、模式、风速、摆风，3D 里出风气流：制冷蓝、制热橙）、电视等设备开关、扫地机器人（每层一台、在自己那层跑；100mm 栅格避障规划：墙、落地家具、楼梯、楼梯井绕开不穿模，桌椅底下能钻，关着的门进不去，路被挡住会重新找路或跳过；能到达的地面弓字形覆盖，地上留青色清扫轨迹；电量低自动走最短路回基站充电、充满接着扫；卡片显示进度、已扫面积、电量、跳过的区域；方案里没放基站时在客厅连通面积最大的那片地面靠北墙处放一个虚拟基站）、门窗（开关、入户门上锁、一键关闭全部门窗）；切换楼层时别的层边滑开边淡出；挑高（层高 > 3.1m）的一层在 2.8m 处剖开，也看得清每个房间；状态只在本次打开有效、不存进方案。想让中控演示更完整，布置家具时记得放上空调、窗帘、电视、灯具（autoElec 会布灯）
