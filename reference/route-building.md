# 整栋楼路线：一页多层 / 描边墙 / 多楼层

### 2D. 整栋楼 / 描边墙路线：cadsplit.py

```bash
python scripts/cadsplit.py 图纸.svg --out <工作目录>/split                      # SVG / DXF：坐标就是 mm
python scripts/cadsplit.py 图纸.pdf --out <工作目录>/split --ref-dim 11720       # PDF：第一张平面最长那道水平尺寸（一般是最外道总尺寸）上标的数
python scripts/cadsplit.py 图纸.pdf --out ... --scale 162.5                       # 或直接给 mm / pt
# 可选：--names 一层,二层,三层  --order ltr|rtl|ttb|btt（楼层在图上的排列）  --wall-color '#000000'
```

- 怎么识别：图元按空白间隔聚成几块 = 几张平面（图例、指北针这些小块丢掉）；墙线颜色 = 能围出最多“墙厚宽度窄条”的颜色；
  所有线栅格化后，墙线之间的窄长白条 = 墙（长边是墙线颜色），按行 / 列拆成矩形 → 墙中线 + 墙厚（吸到 100 / 120 / 150 / 200 / 220 / 240… 常用值）；
  同一直线上的墙段连成墙线，中间的缺口看里面画了什么：墙内部有玻璃线 = 窗，只有两侧面线 / 门框线 = 门（量房图常把门洞画成一块），空的 = 门洞；
  墙端和前方的柱 / 垂直墙之间画了门窗线的也接上；外围非墙色的长窄条 = 玻璃墙 / 玻璃栏杆（整段落地窗）；涂黑块、比墙厚的方块 = 柱；
  各层按墙线重合最多的平移自动对齐到同一坐标系。
- 输出：`building_draft.json`（整栋楼 HouseSpec 初稿，每层带底图）、`check<i>.png`（红墙 / 绿门 / 蓝窗 / 橙门洞 / 紫柱 / 青楼梯候选 / 品红电梯候选 / 黄开洞候选）、
  `floor<i>.dxf`（每层干净的 mm DXF，可再交给 cadvec 或别的软件）、`floor<i>.png`（对齐的底图）、`report.json`。
- `_candidates`（要人工确认）：楼梯 = 等间距平行短线组（rect、踏步数、走向），电梯 = 楼梯区里三面墙围成内宽 0.75~1.45m 的小间，开洞 = 成片 45° 斜线。
- 认不出来要人工补：房间名（文字常被炸成线 / 三角面）、门的开向和类型、窗台高、层高、楼层顺序、楼梯上下方向；
  **PDF 里门块和墙同色时认不出门**（只有 SVG / DXF 的门窗图层能认），要对照原图补；PDF 的坐标精度受出图比例限制（1:400 左右约 ±20mm），按标注数字修。
- 实测（格林御庭 2-9 栋，5 层并排在一张 A0 上）：SVG 输入 5 层墙体、门窗、玻璃栏杆、柱全部识别，三层 8 个房间开间进深与标注 0 误差；
  PDF 输入（--ref-dim）比例误差 0.03%，房间尺寸与标注差 ≤ 20mm，门要人工补。
- 下一步：写生成脚本读入 `building_draft.json` 补齐（模板 `reference/example-gen-building.py`），再 build.py + check.mjs。

### 整栋楼 / 多楼层（别墅、自建房、联排、复式）

一张图纸上有几层平面（或几张图各是一层）时，做成**一个**多楼层设计器，不要拆成几个 HTML：
- spec 写成整栋格式：`{"name": 楼名, "slab": 楼板厚, "floors": [ {"name": "一层", "height": 层高, "walls": ..., ...}, ... ]}`，floors 从最低一层往上排，每层就是一份普通 HouseSpec（walls / rooms / furniture / autoElec 都照写），每层可以有自己的 `underlay`（原图里这一层那一块），build.py 会逐层打包。格式见 `reference/spec-format.md`“整栋楼”。
- 所有楼层用**同一个坐标系**（上下层对齐：同一根柱、同一面外墙在各层坐标相同），一般取主体左墙内皮 / 北墙内皮为原点。
- 楼梯用家具 `stairU`（U 形三跑）/ `stairRun`（直跑，`opt.flat` 为平台），`h` = 层高 + 楼板厚；上层楼板在楼梯上方开洞写 `voids`（楼梯井、挑空、采光井；`depth > 0` 是下沉区 / 下行楼梯口）。
- **楼梯怎么从平面图读**（各层楼梯必须接得上：下层梯段的终点 = 上层楼梯洞口的落地边）：
  - 国标 / 教材画法（每层平面图都是在本层楼面以上约 1.2~1.5m 处水平剖开往下看）：
    - **底层**：剖切面在第一个休息平台下方，第一跑被剖断，用 30° / 45° 折断线表示（为了和踏步线区分），只画剖切面以下那一截，只标“上”；剖切面以上的部分不画或画虚线。
    - **中间层**：折断线画在梯段中段，一侧“上 ×× 级”、另一侧“下 ×× 级”，下行梯段被上方梯段挡住的部分也以折断线结束（双折断线）。
    - **顶层**：剖切面在楼梯以上，踏步完整、**没有折断线**，只标“下”，楼面临空一侧画水平栏杆。顶层图是唯一能看到整部楼梯的平面图。
  - 设计器已按这个画：直跑梯段高过剖切面（`opt.cut`，默认 1500）的踏步画虚线、交界处画 45° 折断线、“上”箭头到折断线为止；上一层楼梯井里自动画出下一层的楼梯（实线、标“下”，不再写“楼梯井”）。图上的折断线在别的高度时，用 `opt.cut` 对齐到图上的位置。
  - 首层：剖切面约 1.2~1.5m。**画实线的是着地的低段**（起步段 + 剖切线以下），45° 折断线以外是剖切面以上的部分，不画或画虚线。所以首层图上“楼梯看起来到某处就断了”，不代表楼梯在那里到顶；它会继续往上，底下净高 > 2.2m 的地方照样能走人、开门（门开在高段梯段下面很常见）。
  - **先分清楼梯两端：哪端着地、哪端连上层**（读反了整部楼梯都会错，方向、层高、洞口全跟着错）：
    - **着地端（起步）**：在下层图上画**实线**、带“上”字和起步圆点 / 箭头尾巴的那一端；常常是一小段短跑（2~3 级）或第一跑的开头，旁边是本层地面、走道。
    - **连接上层的到达端**：在下层图上要么在折断线以外（不画 / 虚线），要么根本看不到；在**上层图**上是洞口边紧贴上层地面（过厅、走道）的那一端，标“下”的起点就在这里。到达端外侧一定是上层能站人的地面，不是洞口、墙、室外。
    - 判断口诀：下层看实线找起点，上层看洞口边找终点；“上”字在起点，“下”字在终点；折断线永远在两端之间、偏向高的那边。
    - 两端定下来再顺着走向数踏步把中间接起来（数踏步，踢面 160~180），终点必须正好落在上层到达端。
  - 设计器会自动检查两端（自查报告里的“楼梯着地端 / 楼梯到达端 / 楼梯净高”）：最低一级离地 ≤ 一级、踩在本层地面上；最高一级 = 楼面到楼面、外侧是上层地面；梯段头顶净空 < 2m 的地方上层必须开洞。有这几条 warn 说明两端弄反了、层高 / 踏步数对不上或洞口没盖住，必须改到没有。
  - 顶层：楼梯洞口里能看到下面的梯段（实线）；洞口里画斜线 / 交叉线的区域是楼板开洞（往下看得到下层梯段），**不是转角踏步**。上层图边上量洞口的分段尺寸（如 830 + 120 = 洞口宽 + 栏板）可以用来核对。
  - 转弯处从两跑分界线端点向外角画放射线 = 扇形转角踏步（`stairU` 的 `winders`，或几块 `stairRun` 平台按矩形近似）；空白矩形 = 休息平台。
  - **每层都严格按自己那张图还原**，不许为了楼梯挪下层的门、家具、墙。下层楼梯照下层图放（直跑段 `opt.steps` 写数出来的踏步数），上层只在洞口范围开 `voids`。两层对不上时先怀疑自己的读法（起步方向、剖切以上的隐藏段、开洞符号），推通了再动手；实在推不通再问用户。
  - 交付前用漫游走一遍：从起步走到上层地面；从高段梯段底下穿过、进出旁边的门；中途往外沿走应被扶手挡住。
  - **先判断是哪种楼梯 / 层高**（不同户型不同判断，别默认“一跑上到二楼”）：
    1. 两层图各数踏步：下层图实线段 + 上层图里看得到的梯段 + 转角踏步，合计 N 级。楼面到楼面 ≈ N × 165~175。
    2. N ≈ 16~19 → 普通层高（约 3m），一部双跑 / L / 直跑楼梯就到上层。
    3. N ≈ 26~34 → **挑高复式 / LOFT（一层挑高 4.5~5.5m）**：楼梯是**多跑盘旋**的（常见四跑三拐角），上面几跑压在下面几跑正上方（踏面之间净空 ≥ 2m）。
       这时下层图只画得到着地的前两跑（画到折断线），后两跑和拐角在剖切面以上，画成虚线或叠在下面梯段上的虚线；上层图洞口里看到的是最后两跑（一排往外、一排往回）和它们之间的转角，**和下层图位置对不上是正常的**——它们本来就不是同一跑。
       推法：从下层的起步段开始，按踏步顺序把每一跑、每个拐角接起来，最后一跑必须落在上层过厅 / 走道边；两排梯段之间的那道线（尺寸里常见 100~120）是中间隔断 / 栏杆，不是楼板栏板。
    4. 层高定下来后：一层 `height` = 楼面到楼面 − 楼板厚；整个上层图里画楼梯的那块（看得到的所有梯段 + 转角）都写进上层 `voids`。
  - 多跑楼梯的写法：每一跑一个 `stairRun`（`z` = 起点高度、`h` = 这一跑升高、`opt.steps` = 踏步数），图上拐角画放射斜线的是扇形转角踏步，用 `opt.winder` 照斜线写（见格式说明）；空白矩形才是休息平台，用 `opt.flat`。扶手自动：外沿临空、或旁边的梯段高差超过一步（上下叠着的两跑）都会装；和相邻梯段 / 平台一步之内接上的地方不装。
  - 下层图按剖切画：被切到的那一跑在 `opt.cut`（剖切高度）处画 45° 折断线、以上虚线；整段在剖切面以上的梯段、平台只画虚线、不画折断线和箭头。
- 识别：多层并排在一张图上 / 描边墙 → 用上面的 cadsplit.py（自动切层、对齐、出初稿）；每层是单独一张图的，各自用 cadvec / analyze 还原后拼成 floors（注意对齐到同一坐标系）。楼层顺序看楼梯能不能接上：下层上行梯段的终点要落在上层楼梯起步处。
- **位图里几层并排**（截图、照片，cadsplit 用不了；每层比例常常不一样）：每层按自己的分段尺寸刻度定 mm/px 和原点像素，各层**完全相同的那条分段尺寸链**（如西侧 220/1590/220/1900）起点对到同一毫米坐标 = 同一坐标系；
  再用 `scripts/gridmm.py 图 OX OY S X0 Y0 X1 Y1 out.png` 给每层逐块叠毫米网格，直接按毫米读墙、门窗、楼梯（比对着像素换算快、不易错）。每层底图用这一层切出来的图。
  完整示例：`reference/example-gen-duplex.py`（挑高复式、四跑三拐角楼梯）。
- 设计器里：左侧“户型”面板管理楼层（改名、层高、排序、增删、复制本层），画面左侧楼层面板切换当前层（PgUp / PgDn）；2D「平铺」把各层平面摆开、点哪层编辑哪层，「单层」只看当前层；3D 顶部楼层条：「整栋」叠成整栋楼、「平铺」各层并排摆开（每层上方有层名牌）、点「一层/二层…」把那一层单独拿出来看（勾「含下层」= 剖切），3D 里点某一层也会单独拿出来；风格（沙盘、彩平图、配色）对单层和平铺都生效。漫游时可以直接走楼梯上下楼（踏步、平台逐级升高，走过半层自动切到那一层；楼梯井、下沉区边上有落差的地方自动装玻璃护栏，人也走不进去；楼梯外沿不靠墙、悬空的那几段自动加扶手，贴墙的段不加；扶手有碰撞，走不出梯段），所以楼梯要按图纸位置放准、`voids` 要盖住楼梯井。有电梯的（别墅常见：楼梯井正中一个内宽 900 左右、三面墙一面开口的小井道，可能只在某一层画了井道墙）每层放家具 `elevator`（同一位置），井道写 `voids` 带 `"shaft": true`（楼板开洞但能站人、不装护栏），漫游时走进轿厢会出现楼层按钮，关门 → 升降 → 到站开门，人跟着换层。所有编辑、水电、报价、导出都作用于当前层；报价可以切“全楼汇总”；撤销 / 重做跨楼层。
- 自查：check.mjs 自动逐层检查，输出 `plan2d_<i>.png`、`overlay_<i>.png`、`plan2d_all.png`、`view3d.png`（整栋）、`view3d_cut<i>.png`（剖到每层），report.json 里 `floors[]` 每层一份。
- **漫游走查（有楼梯必做）**：`node scripts/walktest.mjs 设计器.html 路线.json`，路线照 `reference/example-walk-route.json` 写（起点 + 一段段移动）。
  看输出：爬楼梯时脚高逐段升高、过半层楼层号 +1、到顶脚高 0；往扶手外 / 墙外走坐标应停住；穿门、从高段梯段底下走过去坐标应能通过。走不通就回去改楼梯分块、高度或洞口。

### 双跑 + 扇形转角楼梯：stairDogleg

别墅最常见的“两跑并排、转角放射踏步”楼梯，一个 key 放出来，不要再用 `stairU` + `winders`（方块堆叠、扶手在转角竖直断开，用户指出“不符合实际”）：

```json
{"key": "stairDogleg", "at": [x, y], "rot": 0, "w": 2400, "d": 3600, "h": 3150, "opt": {"winders": 7, "gap": 120, "start": "right"}}
```

- 两跑并排（`start` 起步侧），背面 180° 扇形转角，踏步线从中间立柱放射；级数 = round(h / 170)，转角 `winders` 级（默认 7），其余两跑平分。
- 内侧扶手绕立柱连续弯过去，立柱自动建。h = 层高 + 楼板厚；上层楼板照常写 `voids`。
- 图上转角是放射线、但两跑不对称 / 转角不是 180° 时，仍按 `stairRun` 直跑 + `opt.winder` 扇形 + `stairRun` 直跑照图拼。
- 自查新增「楼梯踏步」：踢面 > 180 或踏面 < 220 报 warn（扇形踏步不查）。

### 地下室 / 场地

- **一行写完**：整栋 spec 顶层 `"site": {"city": "福州", "grade": 0, "soil": true, "lawn": 1800}`——
  `grade` 室外地坪标高（mm，0 = ±0.000），楼面比它低 1m 以上的楼层是地下层：楼层条、楼层面板标“地下”；
  `soil: true` 在每个地下层四周画一圈 1.5m 宽的半透明土层（四条长条，不是一整块“回”字），一眼分出地上地下；
  `lawn` 在地坪所在那层外圈铺一圈草坪（宽 mm），比土层高 20mm 不闪。
  生成的都是 `opt.site = true` 的自由模型：点选优先级最低（点到别的家具优先选别的）、自查不报“不在任何房间内”、不是墙所以不改外墙尺寸。
- 自己用自由模型做土层、路沿、花池时同样写 `"opt": {"site": true}`；叠放的自由模型顶面 / 底面平齐时，载入时自动错开 20mm（不闪）；自由模型按实际轮廓点选（“回”字形中间空的地方点不中它）。
- 路沿、花池边这种矮墙要用墙建时：整段开 `hole`、`sill` ≤ 300，这种墙不算进外墙尺寸。
