# 管线排布规则（强电 / 照明 / 弱电 / 给水 / 排水）

设计器的「水电」图层在点位之上自动排出每一根线、每一根管，规则如下。代码在 `designer/src/model/mep.ts`。
**依据的规范条文**（正式施工前以现行规范原文和电工 / 设计师核算为准）：

| 规则 | 依据 |
|---|---|
| 分支回路铜芯导线截面 ≥ 2.5mm²，进户线 ≥ 10mm² | GB 50096-2011《住宅设计规范》8.7.2 |
| 空调插座、一般插座、照明分路设计；厨房插座**应**独立回路，卫生间插座**宜**独立回路 | GB 50096-2011 8.7.2 |
| 除壁挂式分体空调插座外，插座回路设剩余电流保护（30mA） | GB 50096-2011 8.7.2 |
| 综合布线与电力电缆平行敷设保持间距（GB 50311-2007 表中 <2kVA 无屏蔽为 130mm），交叉时垂直交叉；设计器按家装通行做法取 ≥ 300mm | GB 50311 |
| 冷热水管上下平行时热水在上，左右平行时热水在左（左热右冷） | GB 50242 |
| 塑料排水横支管标准坡度 0.026 | GB 50015 |

## 回路划分（自动）

| 回路 | 内容 | 导线 | 断路器 |
|---|---|---|---|
| L 照明 | 全部灯具，按房间成组，每路 ≤ 16 盏 | BV 2.5mm² | C16 1P+N |
| S 插座 | 一般插座按房间成组，相邻房间拼一路，每路 ≤ 12 个 | BV 2.5mm² | C16 1P+N 30mA 漏保 |
| K 厨房插座 | 厨房插座 + 烟机 + 厨房 16A，独立；≥10 个分两路 | BV 4mm² | C25 1P+N 30mA |
| B 卫生间插座 | 各卫生间插座，独立 | BV 4mm² | C20 1P+N 30mA |
| AC 挂机空调 | 两台一路 | BV 4mm² | C20 1P+N（壁挂空调可不带漏保） |
| ACF 柜机空调 | 每台一路（柜机旁的 16A 插座） | BV 4mm² | C25 1P+N |
| WH 电热水器 | 每台一路 | BV 4mm² | C25 1P+N 30mA |
| EV 充电桩 | 每个一路（7kW 交流桩） | BV 6mm²，PVC Φ25 | C32 1P+N 30mA |
| 总开关 | | 进户线 ≥ 10mm² | 2P 63A，不带漏保（避免一处漏电全屋断电） |

选中插座 / 灯，右侧「所属回路」可以手动改到同类的另一路。

## 走线方式（按家装水电施工的行业做法）

行业通行做法（多家装修公司施工标准、验收要点汇总，正式施工以现行规范和施工图为准）：
**墙面横平竖直**（只竖向开槽，后期挂柜打孔避开管线的水平 / 竖直方向即可），**地面可以点对点**（地面一般不打孔，省管省线），
**厨房、卫生间、阳台电线全部走顶**（地面有防水层、长期潮湿，严禁在厨卫地面埋电线管），**水走顶**（漏水好查、不破坏防水），
**电上水下、水电不同槽**（交叉时电管在上、水管在下），**强弱电分开 ≥ 300mm**（交叉处垂直交叉、包锡箔），
**冷热水左热右冷**、出水口中心距 150、热水管外包保温，**排水用 45° 弯头 / 斜三通**（禁止 90° 直角和正三通，容易堵），横支管坡度 ≥ 2.6%（地漏支管 ≥ 3%），
电线管转角用**大弧弯**（弯曲半径 ≥ 6 倍管径，不用直角弯头），一管一回路。设计器这样排：

- **分道**：每个系统离墙面有固定的“车道”，A* 偏离车道越远代价越高（每偏 100mm +35%）：
  | 系统 | 位置 | 离墙 |
  |---|---|---|
  | 强电插座回路（走地） | 地面沿墙 | 150 ~ 300（避开踢脚线、柜体钉、门槛石） |
  | 网线（走地） | 地面沿墙 | 450 ~ 600（和走地强电拉开 ≥ 300） |
  | 照明 / 插座（走顶） | 顶面沿墙角外侧 | 150 ~ 300（在水管外侧：电上水下、不同槽） |
  | 给水（走顶） | 顶面贴墙角 | 0 ~ 100 |
  | 给水（走地） | 地面贴墙 | 50 ~ 200 |
  | 照明灯接灯 | 顶面 | 不限（灯头盒之间可以横穿房间顶面） |
  | 排水 | 降板 / 垫层内 | 不限，最短 + 45° 斜接 |
- **强电插座回路**：从强电箱出发，**一个房间一个房间**接过去（按穿墙代价算的走线距离，先近后远），每个房间里从离入口最近的点位开始**沿墙一圈**（顺时针 / 逆时针取短的）依次串过各点位——电工就是这么穿线的；默认走地，可切走顶。
- **照明回路**：固定走顶；开关线从开关接到它控制的最近一盏灯（灯头盒引下）。
- **厨房、卫生间、电热水器回路**：一律走顶；走地的插座回路、网线穿厨卫地面代价 ×8 / ×4。
- **弱电**：弱电箱到每个网口 / 电视口各拉一根（星形，中间不接头），走地；**吸顶无线 AP、吸顶音箱的网口在吊顶里**（autoElec 放在设备正上方，PoE 网线走顶）。强电 300mm 以内顺着走代价很高，只垂直交叉；两箱出线 1m 内豁免。
- **给水**：进户总阀出冷水、热水器出热水，树状接到已有管线上（三通）；下游用水点 ≥ 3 个的干管 PPR De25，其余 De20；默认走顶。热水管和冷水管成束并行（相隔一格 100mm）。
- **排水**：墙排水口、地漏接同一房间的立管（管井 / 下水口），PVC De50，坡度 2.6%，**拐弯自动切成两个 45°**；原有地漏所在房间没有立管时按原结构直排；离立管超过 6m 的照样排，并提示起点要垫多高（或改用污水提升器）。
- **地面走法**（水电面板「地面线管走法」）：横平竖直、沿墙分道（默认，整齐、后期好定位）/ 两点一线（在格子路径上拉直，同一房间地面能直连就直连，不穿墙、不过开洞、不进厨卫）。
- 寻路：100mm 网格加权 A*（启发值 ×1.2），拐弯代价 = 1.2m 直线（少拐弯），优先从门洞过墙，承重墙代价约等于绕 15m，同类管线不重叠、挨着并排成束。
- 画法：电线管 / 网线转角画成 R150 的弧弯；水管直角；排水 45° 斜接；实线 = 走地、长虚线 = 走顶。点位离地高度标注自动避让（同一处同高只标一次，放在朝房间的一侧，放不下就不标）。

## 手动编辑（自定义连接）

- **画管线**：顶部「管线」工具或水电面板「管线编辑」里选系统（插座回路 / 照明 / 网线 / 冷水 / 热水 / 排水），逐点点击，默认横平竖直（Alt 任意角度）；
  点到点位、强弱电箱、进水阀、热水器、管井 / 地漏、别的管线（拐点或线上）会自动吸附并结束，吸附目标和上一点不在一条线上时自动补拐点；双击 / 回车结束，Backspace 撤一个点，Esc / 右键取消。
  勾「自动寻路」时只点起点和终点，中间按上面的规则自动排。画好的线两端接到哪路回路就自动并进那一路（算回路长度、材料）。
- **改**：选中一条管线 → 拖顶点（对齐前后拐点，Alt 不对齐）、拖一段沿法向平移、双击线段加拐点；手画的线两端也能拖，松手吸附。
  右侧属性：系统、走地 / 走顶、规格、接入回路、名称；「按规则重新走线」（手画的）/「恢复自动走线」（自动排的）。
- **删**：选中顶点按 Delete 删拐点；没选顶点按 Delete 删整条——手画的直接删，自动排的记进 `mep.removed`，面板里「恢复删掉的自动走线」。
- 存储：`plan.mep.custom`（手画）、`mep.edits`（改过的自动走线，两端点位没动才生效）、`mep.removed`（删掉的自动走线）。

## 纠错规则（`designer/src/model/mepCheck.ts`）

自动排的线是按规则算出来的，有问题只给**提示**；手动画 / 改 / 删过的线违反规矩按**警告 / 错误**报，同时进右侧「检查」页。每条都能点击定位，能自动处理的带修复按钮，「一键纠错」把所有能自动处理的错误 / 警告依次处理。

| 检查 | 级别（手动） | 自动修复 |
|---|---|---|
| 手画管线一端悬空（没接到点位 / 箱子 / 别的管线） | 错误 | 吸到最近的点位 / 管线（补拐点） |
| 走地的管线穿过楼梯井 / 挑空（没有楼板） | 错误 | 重新走线 / 恢复自动 |
| 电线管、网线走地穿过厨房 / 卫生间地面 | 警告 | 改成走顶 / 重新走线 |
| 穿承重墙（不在门洞位置） | 警告 | 重新走线 / 恢复自动 |
| 排水管 90° 直角弯、回头弯 | 警告 | 重新走线（自动 45°） |
| 网线和强电平行 ≥ 0.6m、间距 < 300mm | 警告 | 重新走线 |
| 水管和电线管平行挨着（< 100mm，同槽） | 警告 | 重新走线 |
| 从强电箱 / 弱电箱 / 进水 / 热水器 / 立管出发顺着相接的管线走不到 = **断了**（删了中间一段，下游全没电 / 没水） | 警告 | 恢复删掉的走线 |
| 点位没有接线 | 警告（删线导致）/ 提示 | 恢复走线 / 自动接到最近的管线 |
| 冷热水左右装反（面对墙应左热右冷，同高度的一对） | 警告 | 对调冷热水点 |
| 一路插座带 > 12 个点位、最远热水点 > 10m（建议回水 / 小厨宝）、排水横管 > 4m（注意降板） | 提示 | — |

## 图上怎么看

- 实线 = 走地，长虚线 = 走顶；棕色虚线 = 排水（箭头指向立管）
- 红 = 插座回路，橙 = 照明，蓝 = 网线，青 = 冷水，玫红 = 热水，棕 = 排水
- 每个回路在最长的一段上标回路编号（L1、S2、K1……），给水标管径
- 进户总阀：青色圆圈里的阀门符号

## 别墅 / 复式 / 多层

每层单独排线，但按整栋楼联动：
- **配电**：有入户门的那层（多个取最低的）是**总配电箱**，其他楼层的强电箱是**分层配电箱**，由总箱里一个 C40 2P 分层开关供电，
  干线 BV 10mm²（火 / 零 / 地，穿 PVC Φ32，沿楼梯间或管井竖向走），长度 = 层间高差 + 两箱平面距离 + 预留 2m；弱电箱同理，主弱电箱拉两根 Cat6 上去（一根备用）。
  水电图上分箱旁标「分箱 ← 一层总箱」，总箱旁标「总箱 → n 个楼层分箱」。
- **进水总阀只在有入户门的那层**（autoElec 也只在这层放）；其他楼层没有总阀时，冷水从相邻楼层经**给水立管 JL** 过来：
  立管放在本层管井里，没有管井就放在离相邻层用水点最近的本层冷水点（上下层卫生间、厨房对齐时立管最短）。
- **热水**：本层没有热水器时，热水从有热水器 / 壁挂炉的楼层经**热水立管 RL** 过来（壁挂炉 `boiler` 也算热源）；全楼都没有热水器才提示。
- **楼板开洞**（挑空、楼梯井）没有楼板：走地的管线（插座回路、网线、走地的水管、排水）绕开，走顶的可以从上面过。
- **首层排水**：独栋 / 联排（有庭院、花园、车库）的首层，排水点所在房间没有立管时直接穿地坪出户（GB 50015：底层排水宜单独排出），标 **CH**，不横穿别的房间；楼上的排水仍要接本层立管，太远会提示。
- **导出**：多层时「导出全楼回路表 + 材料清单」逐层列出回路和材料，最后按材料名汇总全楼（含分层干线、立管、出户管）。
- 3D 管线透视里立管从楼板下一直通到顶棚，首层出户管往地下走。

## 生成方案时

spec 里写 `"autoElec": true` 会自动放进水总阀；想指定进户位置就在 `elec` 里写 `{"kind": "waterIn", ...}`。
`"mep": {"power": "ceil", "water": "floor", "floorStyle": "direct"}` 可改默认走法，`mep.custom` 可以预先画好管线（见 spec-format.md）。管井 `shaft`、下水口 `sewer` 要按图放准，排水就接它们。
