# 独栋别墅（车库、庭院、多层、挑空）

### 独栋别墅（车库、庭院、多层、挑空）

独栋别墅图和公寓图的区别：主楼外面还有**车库、庭院围墙、车道口、车棚、泳池**，楼里常有**挑空客厅、电梯、地下室 / 设备间、露台（车库顶上、顶层）**。按下面认：
- **楼层**：一般 2~4 层（可能有地下室），一张图里几层并排或每层一张，照“整栋楼 / 多楼层”写成一个 floors；首层常挑高 3.3~3.6m，楼上 3.0m 左右，楼板 120~150。所有层用同一坐标系，原点取整栋最西北的外墙外皮（车库凸出去就以车库为准）。
- **车库**：图上标“车库 / 车位 / 停车”，外墙上有一个 2.4~6m 宽的大洞口（单车位 ~2.7m、双车位 ~5m），常画一条粗线或虚线门板、有时写“卷帘门 / 电动门”→ 门型 `garage`（电动卷帘门，2D 画门板 + 室内侧卷帘箱虚线，3D 门板卷进门头，中控能开关）。车库和主楼之间那扇门（常通设备间 / 玄关 / 洗衣房）照普通门写。车库地面 `mat: "epoxy"`（环氧地坪）。按图画的车位放 `car` / `suv`（车头朝里：rot 让车头朝车库内墙），壁挂充电桩 `evCharger` 挂在车头正对的墙上；储物架、工具台靠侧墙。
- **庭院**：主楼外围一圈细墙线（围墙 / 栏杆）圈起来的地方就是院子，标“庭院 / 花园 / 前院 / 后院 / 天井”。围墙照墙画、厚 150~240，用 `low(...)` 那种写法开整段 `hole`（`sill` = 围墙高 1200~1800，`head` = 层高）：设计器只砌到围墙高；车道口、人行门写成 `sill: 0` 的通高 `hole`（两边门垛自动只砌到围墙高），再在洞口上放 `gate`（庭院大门，宽度按洞口）。院子地面 `mat: "paving"`（石材）/ `grass`（草坪），草坪块、汀步、泳池、凉亭、车棚、乔木、灌木、草坪灯、烧烤台、叠水景墙、秋千、躺椅、遮阳伞都在“别墅 · 庭院”里。院子必须被围墙 + 主楼外墙完整围住，否则识别成室外（没地面、不布水电）。
- **车棚**：院子里画一个虚线矩形 + 对角线 / 四角立柱、标“车棚 / 车位”的 → 家具 `carport`（单车位）/ `carport2`（双车位），底下再放一辆车；车棚、凉亭、草坪、汀步、乔木不参与家具重叠和通道检查（本来就压在别的东西上面）。
- **泳池**：画蓝色或水波线的矩形、标“泳池 / 水池” → `pool`（w × d 照图，长边方向用 rot）。
- **挑空**：上层图在客厅上方画斜线 / 交叉线、标“挑空 / 上空 / 客厅上空”→ 上层 `voids` 写这块矩形（`name: "客厅挑空"`），四周用栏板（`hole` + `sill: 1100`）或实墙围住；挑空里可以放 `chandelier`（水晶大吊灯，挂在上层顶面垂进客厅）。
- **电梯**：楼梯旁一个约 1.5 × 1.5m 的小井道、标“电梯” → 每层同一位置放 `elevator`，上层井道 `voids` 带 `"shaft": true`。
- **常见房间**：玄关、客厅、餐厅、中西厨、老人房（一层带卫生间）、主卧套房（主卧 + 衣帽间 + 主卫）、家庭厅 / 起居厅、书房、茶室、影音室、台球室 / 棋牌室、健身房、酒窖、桑拿、保姆房、设备间 / 锅炉房（壁挂炉 `boiler`、地暖分集水器 `manifold`、中央软水机 `waterSoftener`、洗衣烘干）、储藏间、露台。对应家具都在“别墅 · 休闲 · 设备”和原有分组里。
- **水电**（`autoElec` 自动）：车库按面积排吸顶 LED 灯、进屋门和车库门两处双控、每个车位一个充电桩电源（`socketEV`，32A 独立回路，壁挂充电桩自带的算一个）、卷帘门电机插座（门头上方）、墙上插座 1.3m 高；庭院沿围墙 / 外墙装壁灯、留防水插座和取水点（浇花、洗车），车棚旁留充电桩电源；露台壁灯 + 防水插座；二三层没有入户门时，每层的强电箱、弱电箱放在楼梯口旁的公共空间（分层配电）；设备间不预留空调、网口。
- 完整示例：`reference/example-gen-villa.py`（三层独栋：双车位车库 + 车库顶露台、庭院围墙 + 车道口、车棚、泳池、凉亭、挑空客厅 + 水晶吊灯、U 形楼梯 + 电梯、主卧套房、茶室、影音室、台球室、桑拿）。
