# 布置图 DXF 路线：整套 DXF 里挑一张还原（含家具块）

### 2E. 布置图 DXF 路线：整套 DXF 里挑一张还原（含家具块）

装修公司 / 设计院给的 DXF 常常是“整套图”：一张原始结构图 + 一张平面布置图（同一套轴网、上下排），还有天花、地材、灯具、空调、文字说明各自的图层；
块里套块（家具块里有子块）；中文图层名、块名、文字是 GBK 被当 latin1 读成乱码（`ÔÇÉè` 这种）。按下面做：

```bash
# 1. 看全图，找出要还原的那一张（一般是“平面布置图”：家具最全、门开向都画了）的 CAD 外框坐标（y 朝上）
python scripts/dxf_prepare.py 图.dxf <工作目录>/selected.dxf --box X0 Y0 X1 Y1     # 只留这一张，展开块、修乱码、按图层统一颜色（墙 7、门 3、窗 4、标注 2、其余 8）
# 2. 墙体初稿：坐标单位一般就是 mm
python scripts/cadsplit.py <工作目录>/selected.dxf --out <工作目录>/split          # 描边墙、门窗洞口、柱
python scripts/cadvec.py   <工作目录>/selected.dxf --out <工作目录>/cad            # 实心墙 / 管井 / 地漏 / 标注
# 3. 家具和设备证据
python scripts/dxfinventory.py 图.dxf --box X0 Y0 X1 Y1 --out <工作目录>/inv        # blocks.json + blocks-*.png 缩略图、texts.json、doors.json、underlay.png
```

- `dxfinventory.py` 的输出坐标 = (x − X0, Y1 − y)，和生成脚本、底图同一个坐标系（底图写 `{"image": "inv/underlay.png", "mmPerPx": 10, "x": 0, "y": 0}`）。
  `blocks.json` 每个块有 `guess`（按块名 / 图层猜的家具库 key，只是参考）；**逐张看 `blocks-*.png` 认家具**：块名多半是匿名的（`*U123`、`A$C...`），门块（带 1/4 圆弧，`guess` 标 door）写进墙的 openings，不当家具。
  一个块里常是一组家具（圆桌 + 4 把椅子、会议桌 + 12 把椅子、L 形办公桌 + 椅子），**拆成一件件放**，不要整组当一个。
- 文字（`texts.json`）给房间名、设备标注：`A/S` 送风口 → `supplyVent`、`A/R` 回风口 → `returnVent`、`无线AP` → `wifiAP`、`嵌入式扬声器` → `ceilingSpeaker`、`强电间 / 弱电间 / 管井`……
  标注文字一般写在设备旁边，可能落在墙里：放进房间里（生成脚本按墙面推出去）。
- 门弧（`doors.json`）：`hinge` 是门轴，`a0 / a1` 是门扇扫过的角度（输出坐标，y 朝下）；找门所在的墙、开向（into = 弧中点那一侧）。
  `cadsplit` / 弧线匹配常漏门：**每个房间都要能进去**——check 报“从入户门到某门没有 ≥ 700 通道”时，先回原图那个房间找漏掉的门（核心筒电梯厅、设备间、前室最容易漏），别乱开门。
- 两段墙在同一直线上、中线差十几到几十毫米（图纸里一侧墙面平齐、厚度不同）：**不要写成两条中线错开的墙**——设计器吸附端点时会把后一段吸成斜墙、吞掉它上面的门。放在同一条中线上，用 `flush` 对齐平的那一侧（或取一样厚）。
- 一整段玻璃幕墙 / 带形窗写一个 `glassWall` 洞口就行，设计器会按被内墙打断的每段墙拆开（交接处留墙垛）。
- **精确取数和逐项对账用 `scripts/dxfaudit.py`**（布置图一定要做，用户会拿原图一件件对）：
  ```bash
  python scripts/dxfaudit.py blocks 图.dxf --box X0 Y0 X1 Y1 --out <工作目录>   # 家具块展开到叶子块：每把椅子 / 每张桌子的插入点、旋转、镜像 + deep-*.png 块定义缩略图
  python scripts/dxfaudit.py cache  图.dxf --box X0 Y0 X1 Y1 --out <工作目录>   # 全部线段缓存
  python scripts/dxfaudit.py q <工作目录> X Y R [图层]                           # 查某点附近的线：墙面、柜子外框、门扇、屏幕的精确坐标
  python scripts/dxfaudit.py walls|doors|furn <工作目录>                         # 三项对账，MISS / FAKE / WALL 逐条处理到只剩能解释的
  ```
  - **家具朝向按块算，不要按“离哪张桌子近”猜**（阶梯教室里椅子离后一排桌子更近，猜出来整排反了）：叶子块的局部正面方向 (fx, fy)（看 deep-*.png：弧形靠背的对边是正面）
    → `vx, vy = fx·sx, fy·sy`，按块旋转角转到世界（DXF y 朝上），再换到设计器 (X, −Y)，`rot = atan2(−X, −Y)`（设计器正面 = rot2(0, 1, rot)）。镜像插入的块里圆弧会变成长短轴相等的 ELLIPSE。
    叠了两遍的块（50mm 内同名）去重。组合块（圆桌 + 椅子、会议桌、工位）读块里的实际图形：桌面是最大的圆 / 多段线，椅子取每把的最大外轮廓、面朝桌心。
  - **图层各有含义，全都要建**：`P_01` 活动家具、`P_02` 固装落地到顶（带 X = 柜门分格 → `cabTall`）、`P_09` 固装悬空到顶（吊柜 / 悬空展示柜 → `cabWall`，旁边常标“展示柜 / 水吧台”）、
    `P_03` 洁具电器（台面外框 + 台盆块：台面长度、进深照外框，水槽 `kit.sink.at` = 台盆中心离台面局部左端的距离）、`J-洁具`（小便斗、隔板）、`P_19` 窗帘、`T_07` 空调设备（吊顶上 4 条平行长线 = 条形风口，旁边的 A/S、A/R 是标它的，不要再放方形风口）、
    `P_07` 完成面（比结构墙面多 50~100：墙按完成面建，柜子、台面才能贴墙）、`Q_01` 原墙柱 / `Q_06` 墙体 / `Q_07` 新建墙填充。**门可能画在任何图层**（`J-DOOR`、设备层），弧也常是折线拟合的——门以 `doors` 对账为准。
  - 读门：门轴 = 弧心，**画成实线矩形的那块门扇是开到 90° 的位置，关门位置是弧的另一端**。所以门扇贴着一面墙、弧扫到另一面墙时，门洞在弧另一端那面墙上（讨论室门开在侧面隔墙上，不在挂屏幕的那面墙上）。
  - 原图标了尺寸的设备照标注放（“150 寸 LED 显示屏 3320*1890”→ 宽 3320、高 1890，位置看完成面上那块同宽的矩形）；原图只写了“地漏（加龙头）”就是地漏 + 龙头，不要放拖把池。没画的东西不要加。
  - 一段墙两侧墙面都变了（新砌墙贴着柱、水吧台背后变薄）：按实际墙面拆段建；同一直线上中线不同的两段在**柱子里**接（柱里加一小段横墙连起来），交接处的错台被柱子挡住，check 不会报错台。原墙里凸出来的一段（450 厚的墙垛）按柱 `structs` 建。
  - 阶梯教室 / 报告厅：`D_01` 地材分格里的弧线 = 台阶边线，过道标高（+0.24 / +0.48…）给每级升高；每级用 `freeExtrude` + `opt.floor: true`（能走上去）照边线描轮廓，桌椅 `z` = 所在那一级的高度。原图没画的最后一级边线按前两条的间距外推，并在交付时说明。
- 完整示例：`reference/example-gen-office-dxf.py`（写字楼培训层：核心筒 8 部电梯 + 2 部消防楼梯、公共卫生间、118 座弧形阶梯培训厅、会议室、开放办公、茶水间、吊顶送回风口 / AP / 音箱）。
