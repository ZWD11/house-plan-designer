# 布置家具、家电和水电（默认要做）

### 5. 布置家具、家电和水电（默认要做）

**开工前先问清**：“图上的所有内容一比一还原、再补图上没有的”还是“只照图放洁具橱柜、其余补最优搭配”（第三次实战按后者理解，用户本意是前者）。默认一比一还原。

### 图上符号逐项清点（第三次实战第一次交付漏了一大半）

动手前出一张「图上符号 → 建模」表（符号、位置、数量、对应 key / 做法），交付时附上；**不认识的符号列出来问用户，不要静默跳过**（如没有图例的红色实心三角）。
符号对照见 `cad-conventions.md`「平面布置图图例」。井道 / 室外设备也要建：

| 图上 | key |
|---|---|
| 带斜线填充的圆（排水 / 雨水立管） | `riser`（Φ110 通高，`h` = 层高） |
| 小空心圆 / 带格栅小方块 | 地漏 `structs` 的 `drain` |
| 带 X 的窄条 + 两个小圆（卫生间管井） | `structs` 的 `shaft` + 里面放 `riser` |
| 矩形 + 几道横线（空调室外机） | `acOutdoor` |
| 墙里一排斜短线（空调位、风井百叶） | `louver`（放在洞口位置，`h` 按百叶高） |
| 井道里的点（强电 / 弱电表箱位） | `meterBox` |
| 带 X 大方框 + DT-1（消防电梯井） | 电梯井墙 + `elevator` |
| 阳台栏板两端的方框（方墩） | `structs` 的 `column`（`w` / `d` 照图） |

公共部分（楼梯间、消防电梯、电梯厅、强弱电井、风井、管井）**默认还原墙体和设备，不布家具**，开工前和用户确认一句。名字写“电梯厅 / 强电井 / 弱电井 / 风井 / 管井 / 空调位”，小于 0.6㎡ 的有名字区域（0.45㎡ 的空调位、管井）现在也显示名字。
门窗编号：C = 窗、TLM / ILM = 推拉门、FMZ = 乙级防火门（甲 = FMJ）、M = 门，**后四位 = 宽高（分米）**：C1518 = 宽 1500、高 1800 → `from/to` 按宽、`sill` / `head` 按高定（窗一般 sill 900，head = sill + 高）。编号宽和尺寸链对不上时两个都记下，交付说明（check 的 `dimConflicts`）。

### 家具库补齐（一个 key 放出来，不要再用自由模型拼）

| 要放的 | 写法 |
|---|---|
| 两侧长度不同的 U 形橱柜 | `uCounter` + `"kit": {"shape": "U", "d2": 1500}`（右侧段长度，左侧段 = 整体 d） |
| 不带柜门的挂衣区 | 定制柜列类型 `hangOpen`（如 `"cab": {"cols": ["hangOpen", "drawer", "hang"]}`） |
| 斜角开放展示格 | `cornerShelf`（`opt.shelves` 层数、`opt.corner` 直角在左 / 右） |
| 室内飘窗台（凸在墙内侧） | 门窗写 `"type": "bayInner"`（窗 + 台面一起生成，`depth` 台面进深）；只要台面时用家具 `bayDeck` |
| 模块沙发 / 沙发 + 脚踏 | `modularSofa`（`opt.n` 格数、`opt.ottoman: true` 带脚踏） |
| 毛绒玩偶、桌面花瓶、书摆 | `plushToy`、`tableVase`、`bookSet`（落地大花瓶仍是 `floorVase`） |
| 双跑扇形转角楼梯 | `stairDogleg`（见 route-building.md） |

**原图画了家具 / 布置的，必须一比一还原**：每件家具的类型、位置、尺寸、朝向照图放（床多宽、桌子是椭圆还是方的、沙发几段怎么拼、柜子分几段、卫生间玻璃隔断和门在哪），图上画了的不能漏、不能用近似件凑；家具库没有的类型，补进 designer 项目（`src/catalog.ts` + 2D `src/draw/symbols2d.ts` + 3D `src/view3d/furniture3d.ts`，`npm run skill:sync`）和格式说明。
同时要能用：门扇打得开、每个房间和门都有 ≥ 700 的通道，人能走进去。图上画法真的走不通的（比如岛台和橱柜之间只留了几十毫米），按能走通的最小改动处理，并在交付时逐条告诉用户改了哪里、为什么。
读图要点（容易认错的画法，拿不准就放大 4 倍逐个看，必要时查资料）：
- 厨房里被橱柜三面围住的大矩形多半是**地面**（U 形厨房的站人区），不是岛台——岛台四周一定留着 ≥ 800 的通道；
- 洞口边线上一段加粗的短线 / 两头短竖线 = 推拉门轨道（玻璃推拉门、隐形门），要建墙 + `sliding` / `pocket`，不是空着；
- 卫生间里一条窄框 + 三个小圆 + 带斜线的小方框 = 嵌入式淋浴（`showerSet`），旁边的小圆是花洒、带十字的圆是地漏；
- 靠墙一条细长圆角框、前面没有电视屏幕符号（梯形 / 加粗短线）的，是矮柜 / 边柜，**不要当电视柜**；沙发背对的那面墙不放电视；
- 单人椅、沙发：加粗的双线 / 厚的那一边是靠背，椅子面朝茶几、餐桌；
- 门扇：门轴在弧线圆心，开向看弧线在哪一侧；门开在哪面墙看门框短线，套房卫生间的门常开在卧室里而不是走廊；
- 沙发是弯的 / 折角 / 蛇形的用 `bendSofa` 按中线描，不要拿直沙发或 `curvedSofa` 近似。
- 墙边的细带也要认：贴墙一条带等距刻度 = 木格栅护墙板，床头那面墙的双线 = 床头背景板 / 软包，都用 `wallPanel`；墙位置上一条分格细长条 = 玻璃隔断 `glassWall`；小灰圆 = 地漏（`structs` 的 `drain`，按图上的位置放）；墙垛、柜子端头的小圆角柜这些零碎也照画。
- 斜墙（非 90° 的转角）设计器会按墙面求交斜接，不用手工凑；画完放大看一眼转角。
- **一个地方一个地方地对**：furnoverlay 把墙（绿 = 承重、青 = 非承重，按厚度画）、门窗洞口（黄）、家具外框（红 / 蓝）都画回原图，按房间切块逐张看，原图上每一笔都要能在叠图里找到对应的东西。
家具库按酷家乐的分类组织（一级：客厅 / 餐厅 / 卧室 / 书房 / 儿童房 / 玄关 / 厨房 / 卫浴 / 阳台 / 家电 / 灯具 / 软装 / 定制柜 / 办公 / 公共空间 / 娱乐健身 / 户外庭院 / 楼梯电梯 / 自由模型，二级按家具类型），251 件，见 `src/catalogTree.ts`。
- **风格款**：沙发、单椅、床、餐椅、餐桌、茶几、书桌、衣柜等有 9 种风格的建模（现代、北欧、新中式、轻奢、日式原木、美式、工业风、奶油风、侘寂：换腿型、扶手、床头、柜门、木色金属色面料），
  spec 顶层 `"style"` 一次设全屋、或单件 `opt.style`（见格式说明「家具风格」）。用户说了风格就写；原图能看出样式（圈椅、罗汉床、格栅床头）也照着选。
- **自由模型**：原图里不是成品家具的造型——背景墙凸块、异形地台、异形吊顶、拱门、弧形墙、格栅、长虹玻璃隔断、台阶、灯带——用自由模型照图搭（`freeExtrude` 按轮廓描），见格式说明「自由模型」。
核对方法：
```bash
python scripts/furnoverlay.py <工作目录>/spec.json --out <工作目录>/furncheck   # 家具外框画回原图（红 = 落地，蓝 = 挂墙 / 吸顶，箭头 = 正面）
```
逐块看 `furn_r*c*.png`：每个框要正好压在原图那件家具的轮廓上，原图上有而没有框的就是漏了。

除非用户只要结构，否则按房间功能放一套完整的家具和家电，让打开就像真的住进去（家具 key 和朝向规则见格式说明）：
- 卧室：床、床头柜、衣柜、挂机空调、窗帘；儿童房可换上下床 / 婴儿床，书房放书桌椅、书架
- 客餐厅：沙发（或 L 形沙发）、茶几、电视柜或壁挂电视、地毯、餐桌椅、餐边柜、柜机或挂机空调、落地窗帘；入户放鞋柜（可加换鞋凳）、饮水机
- 厨房：整体橱柜（含水槽灶台烟机）、冰箱；空间够加洗碗机、电器高柜；燃气热水器常挂在厨房或阳台
- 卫生间：马桶、浴室柜、淋浴房或一字隔断、电热水器（挂在马桶/淋浴上方，或用燃气热水器）、浴霸、毛巾架；放 `sewer` 下水口和 `drain` 地漏
- 阳台：洗衣机（+ 烘干机）、晾衣架、洗衣池柜，放地漏
- 别墅：车库（车、充电桩、储物架、工具台）、庭院（草坪、汀步、泳池、凉亭、车棚、乔木、灌木、草坪灯、烧烤台、景墙、秋千、躺椅、遮阳伞、大门）、休闲（台球桌、麻将桌、茶台、影院沙发、三角钢琴、吧台、桑拿房、挑空大吊灯）、设备（壁挂炉、分集水器、软水机），见 route-villa.md
- **按现实装修的常理摆**（设计器是正式装修前的预看，每样东西都要真能这么装）：
  - 书桌对窗时离墙 ≥ 300（给窗帘和暖气留位），窗帘前 150mm 内不放落地家具；高于窗台的柜子、书架、冰箱不放在窗前 400mm 内
  - 阳台 / 推拉门旁的柜子收进门旁的墙垛，不压门洞；推拉门洞前 400mm 内不放家具（check 报「窗帘活动区」「推拉门被挡」「高柜挡窗」）
  - 浴室柜贴着隔墙、墙另一侧是衣帽间时不用再缩衣柜：自动水电的镜侧插座只放在浴室柜所在房间这一侧
  - 手写了强电箱 / 弱电箱（`elec` 里的 `panel` / `weak`）就不会再在入户门旁自动放一组；自动放时避开高柜（餐边柜不用断开）
  - 挂机空调、热水器、壁挂炉、吊柜、电视、镜柜、装饰画只能挂在**实墙**上，不能挂在窗洞 / 窗帘盒 / 门洞的位置，也不能和窗帘叠在一起；空调优先放靠外墙（好打孔走管）的侧墙，房间里没有合适实墙时放在床头墙上方，别对着门
  - 橱柜窗前那段不做吊柜（`kit.wallLegs` 只写其他段）；燃气热水器挂在厨房靠外墙的窗边实墙上
  - 每个卫生间都要有热水来源：离厨房燃气热水器近的共用，远的各放一台电热水器（挂在马桶上方或淋浴区旁边的实墙上，不要挂在浴室柜镜子上方）
  - check 会报「挂墙位置」「橱柜吊柜挡住窗户」，必须清零
- 窗帘：住人的房间（卧室、客餐厅、书房、茶室……）每扇窗都放落地窗帘，**宽度必须盖住整个窗洞，两侧各多出 100~200**；转角窗两面墙各放一幅；落地窗 / 窗紧挨着阳台门的，一幅连门一起盖住。check 会报「窗帘没盖住窗户」
- 软装点缀：绿植、地毯、装饰画、落地灯；家具库 160 多件，按户型面积和风格挑（U 形 / 弧形沙发、圆餐桌、卡座、酒柜、L 形橱柜、双盆浴室柜、独立浴缸、猫爬架等都有，见格式说明）
- 地面铺装：默认用 `mat` 预设；用户说了具体的砖（“客厅 800×800 灰色大板”“卫生间 300×300 斜铺”“主卧人字拼木地板”），写进房间的 `tile`（格式见格式说明“自定义铺砖”），设计器会按砖的尺寸、缝宽和铺法一块块铺，报价按排出来的片数算
- 用户点名想要的效果风格（沙盘效果图、彩平图、奶油风、原木、莫兰迪……）写进 spec 的 `look`
- spec 里写 `"autoElec": true`：设计器按房间、门窗和这些家具自动生成全套水电点位并关联开关（餐桌 / 岛台上方吊灯、各功能区灯、全屋覆盖补筒灯不留暗区、插座按墙长补齐，规则见格式说明），一般不用手写 elec
- 管线自动排布（不用写）：水电图层上自动排出强电插座回路、照明回路、网线、冷热水、排水的走线，并给出回路表（断路器 / 线径 / 长度）和材料清单，规则与规范依据见 `reference/mep-rules.md`。所以**强电箱、弱电箱、管井、下水口、热水器要放对**：缺强电箱排不出电路，缺弱电箱排不出网线，没热水器没有热水管，排水接管井 / 下水口。autoElec 会自动放进水总阀（`waterIn`），知道实际进户位置就手写。**别墅 / 复式**：总箱在有入户门那层，其他层是分层配电箱（自动算干线）；进水总阀只放在入户层，其他层由给水 / 热水立管接上来（立管放管井，没有就放在上下层对齐的用水点），所以上下层的卫生间、厨房、管井要按图对齐放准；壁挂炉也算热源；挑空、楼梯井上不走地面管线；有庭院 / 车库的首层排水直接出户。全楼材料清单在水电面板导出

放完再跑一次 check，处理 `issues` 里的 `[warn]`（家具重叠、嵌进墙里、挡住门扇、马桶离下水口太远、点位被柜子挡住等）。
**`[error]` 和 `[warn]` 必须清零才能交付**：用户打开设计器，右侧“检查”页会把它们标成红色 / 橙色，看起来就是“有错误”。不要觉得问题小就留着。
确实改不掉的（原图就是这么画的），交付时逐条说明原因。
`[info]` 级别的提示可以留着（比如家电附近缺少插座，多半是家电没靠墙）。
